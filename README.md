# cpp-calculator

Финальный проект: калькулятор


## Правила оформления кода:

- Расставляйте правильные отступы.
- Давайте переменным информативные названия (без сокращений и транслита).
- Соблюдайте стиль именования переменных и функций.
- Не объявляйте несколько переменных в одной декларации.
- Между функциями оставляйте пустую строку.
- Фигурные скобки расставляйте так, как в примерах и авторских решениях, — { на строке с командой, } на отдельной строке.
- Не опускайте фигурные скобки.
- Избегайте магических чисел.
